# demo-go — Go + go test

Баг: `calc.Average` делит на `len(values)-1` (`calc/calc.go`). Существующие тесты его **не ловят** →
агент сам пишет регрессионный Go-тест, убеждается, что тот падает на исходном коде, исправляет и проверяет.

Пример жалобы: «Average([]float64{2, 4}) возвращает 6, а должно быть 3».
